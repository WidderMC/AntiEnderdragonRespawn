## Download: [Here](https://modrinth.com/datapack/antienderdragonrespawn)

### How it Works
It Kills all End Crystals that are near the Portal

### Use Case
This is especially useful for multiplayer servers where players have built structures in the End. It prevents other players from respawning the Ender Dragon and accidentally destroying nearby builds.

### Mods
- If you use Fabric you must have a version of [Fabric API](https://modrinth.com/mod/fabric-api) also installed
- If you use Quilt you must have a version of [Quilted Fabric API](https://modrinth.com/mod/qsl) also installed

Remove the Mod / Datapack to be able to Spawn the Dragon again.
